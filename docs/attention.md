# «Требует внимания»

Сводка для руководителя: что из его проектов требует вмешательства сейчас.
Правила фиксированные и видны в интерфейсе («Как задачи попадают в список»);
ИИ, оценок и скрытых весов нет. Код — `backend/src/Attention.php`.

## Что учитывается

- Проекты, где пользователь — руководитель (`owner_id`) и участник, кроме архивных.
- Задачи всех исполнителей, кроме статуса «Готово».
- Время — UTC сервера на момент запроса.

## Правила

| Код | Название | Срочность | Когда срабатывает |
|---|---|---|---|
| `overdue` | Срок прошёл | высокая | `due_at` ≤ сейчас |
| `blocked` | Заблокирована | высокая | статус «Заблокирована»; показываем, сколько времени задача не менялась, и последний комментарий — там команда обычно пишет причину |
| `mention` | Ждут вашего ответа | высокая | после последнего комментария руководителя другой участник написал комментарий, где есть имя руководителя (основа имени: «Анн» → «Анна», «Анне», «Анну») или слово «руководитель» в любой форме. Снимается ответом руководителя в задаче |
| `due_soon` | Скоро срок | обычная | сейчас < `due_at` ≤ сейчас + 48 ч |
| `unassigned` | Нет исполнителя | обычная | `assignee_id` пустой |
| `stale` | Нет движения | обычная | статус «Открыта» или «В работе», и последнее изменение задачи и последний комментарий — 3 дня назад и раньше |

Задача может совпасть с несколькими правилами — все они перечислены с фактами.
Порядок: больше срочных причин → больше причин всего → ближе срок → номер задачи.

## Как с этим работать

«Разобраться» открывает обычную карточку задачи справа от списка: можно прочитать
всю переписку, ответить, поменять статус, исполнителя или срок. После сохранения
сводка пересчитывается: например, ответ снимает «Ждут вашего ответа», назначение
исполнителя — «Нет исполнителя». Фильтр по причине — кнопки над списком.

## Допущения и ограничения

- «Руководитель» — владелец проекта. Другим участникам пункт меню не показывается.
- `mention` — простое текстовое правило: оно может сработать на «Анна, спасибо!»
  и не сработать на просьбу без имени. Это осознанный выбор в пользу прозрачности.
- «Просмотрено / отложить» нет: задача уходит из списка, только когда устранена причина.
- Пороги (48 часов, 3 дня) — константы в коде, в интерфейсе не настраиваются.
